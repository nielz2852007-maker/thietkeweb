Xin chào, tôi là [Tên của bạn]

Tôi là một Lập trình viên Web Front-end. Tôi đam mê xây dựng các giao diện web tối ưu SEO và hoàn toàn tuân thủ các tiêu chuẩn Web Accessibility (WCAG).

  • Xem dự án
  • Liên hệ với tôi

Về tôi

Với hơn [X] năm kinh nghiệm trong lĩnh vực phát triển Web, tôi luôn đặt trải nghiệm người dùng (UX) và hiệu năng lên hàng đầu. Các sản phẩm tôi làm ra không chỉ phục vụ người dùng thông thường mà còn hỗ trợ tốt cho những người khiếm khuyết thông qua việc ứng dụng triệt để Semantic HTML và WAI-ARIA.

Kỹ năng chuyên môn

  • HTML5 Semantic, CSS3
  • JavaScript (ES6+), TypeScript
  • React.js / Vue.js
  • Tối ưu hóa SEO On-page
  • Web Accessibility (WCAG 2.1 / ARIA)
  • Git & GitHub

Dự án tiêu biểu

[Tên dự án 1]

Một ứng dụng thương mại điện tử với trải nghiệm mua sắm mượt mà, tối ưu hóa tốc độ tải trang và đảm bảo tương phản màu sắc chuẩn WCAG.

Công nghệ sử dụng:

  • HTML5
  • SASS
  • JavaScript

Công nghệ sử dụng:

  • React.js
  • Tailwind CSS
